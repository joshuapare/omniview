# End-user density refinement

This revision supersedes references to an explicit Apply Local Field button in the initial contract/evidence. Configuration now contains only immutable Name/Namespace and Replicas. Valid replica input patches the fixture-owned path immediately. Invalid or incomplete input remains local, displays a field error and blocks mode/provider/review changes until corrected or reset. Reset Local Input discards only uncommitted invalid input, never committed source.

Owned-path, revision and preservation details now appear in Plugin Author diagnostics, not the Configuration view or footer. Footer status stays empty except actionable errors. The contract's pending-field and scoped callback requirements remain unchanged. Fresh captures replace every earlier screenshot at the new immutable publication commit; original assets remain immutable historical evidence.
