Exact mapping (all read-only; no owned mutation paths):
Both: apiVersion/kind -> destination/version context and source. metadata.name -> resource badge. Pod metadata.namespace -> persistent destination context. timestamp -> collected-at UTC fact; window -> collection-window fact. Interval-start is timestamp minus window, derived display only, never a new API field.
Node: usage.cpu -> exact CPU quantity column; usage.memory -> exact memory working-set column. Other ResourceList keys and unknown metadata/fields belong in retained source, never silently normalized. No percentages or denominators are inferred.
Pod: containers[i].name -> container row and local filter. containers[i].usage.cpu / .memory -> exact quantity columns. All container samples share timestamp/window. Filtering hides rows only; it does not alter source. ContainerMetrics name corresponds to pod.spec.containers per upstream schema, but no workload data or limits are guessed.
Source: all paths, including unknown fields and quantities, remain read-only. Fixture source has no annotations or credentials. Production must apply privacy projection to potentially sensitive metadata before rendering; projection must never be submitted.
