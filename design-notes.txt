Real admission and ownership may impose restrictions. GitOps-owned fixture blocks review; route production users to owning source, never auto-adopt or force conflict.
Target label key/value → spec.selector.matchLabels[key]. Target all workloads → omit selector and targetRefs. Service picker → spec.targetRefs[i].group="", kind=Service, name; namespace omitted (same namespace only). Target modes are exclusive. Sidecar/ambient choice is mock capability context, not manifest data. Root namespace is installation-specific; no guessed mesh root default.
AuthorizationPolicy action select → spec.action. CUSTOM provider input → spec.provider.name, only serialized for CUSTOM. Rule rows add/remove spec.rules[i]. Row namespace list → from[0].source.namespaces[]. Method, path and destination-port lists → to[0].operation.methods[], paths[], ports[]; ports remain strings. Rules OR, sources OR, operations OR, conditions AND. Empty rule always matches; omitted rules never match. ALLOW without rules allows nothing; other policies still participate. CUSTOM before DENY before ALLOW. AUDIT requires plugin and does not enforce access. HTTP-based DENY can match missing TCP attributes; warn and scope ports.
PeerAuthentication mode select → spec.mtls.mode. Empty selection omits mtls; UNSET explicitly inherits. Repeat port rows → spec.portLevelMtls[workloadPort].mode, never Service ports. Validate 1–65535 and nonempty selector. Ambient DISABLE blocked. STRICT rejects non-mTLS bypass traffic. Workload policy takes precedence over namespace and mesh, not arbitrary list order.
RequestAuthentication issuer rows → spec.jwtRules[i].issuer, audiences[], jwksUri. URL optional: omission allows discovery, not proof of resolution. Issuer need not be a URL. No JWT token, credentials or private material collected. Missing token accepted; invalid presented JWT rejected. Requiring JWT needs separately reviewed AuthorizationPolicy; never implicitly create it.

DRAFT CONTRACT
Form-to-source is a bounded generator. Unedited switches preserve exact demonstrated generated text. ANY manual source edit, valid or invalid, keeps exact raw text and disables Form edits and Review. This is honest fallback, not AST round-trip support. Unknown fields/comments/exact large numbers are not parsed or normalized after manual source edits. Production must reuse existing AST editor for lossless supported edits. No resource values persist. Explicit mode preference is not persisted in this prototype; production should reuse existing preference. Browser reload clears drafts. A source edit locks resource switching to avoid accidentally dropping source. Edit fixture button locks identities; select a kind before switching to its edit fixture.
