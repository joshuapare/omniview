COVERAGE AND OWNERSHIP
Both listed kinds have outcomes, ownership/provenance, read-only privacy projection and explicit action boundary. Namespaced fixture uses Deployment reference, cluster fixture uses Node reference; no namespace picker for cluster objects. Treat both as controller-generated evidence in every ownership state. Missing owner does not grant create/edit permission or turn evidence into a user-authored document. No create, patch, delete, re-evaluation or rescan endpoint is invoked or invented. Existing host delete flow, if actually authorized, needs explicit destination/UID and confirmation that evidence deletion does not repair policy failures. No status edit. No metadata edit shortcut.
Provider: Kyverno add-on owns these GVK-specific inspection sections; host owns frame, discovery, RBAC and navigation. Unknown versions retain original representation through host fallback; this mock displays a fixed unsupported fixture, not a lossless parser.

FIELD → CONTROL → PATH (all inspection-only; zero owned mutation paths)
Identity → locked title/destination → apiVersion, kind, metadata.name, metadata.namespace (absent for cluster kind).
Creation → absolute UTC time → metadata.creationTimestamp. No stale relative age used as health signal.
Owner → reference facts and inspect-reference button → spec.owner.apiVersion/kind/name/uid/controller/blockOwnerDeletion. Last two optional booleans remain omitted when absent, not defaulted. spec.owner is not metadata.ownerReferences. Actual ownerReferences/managedFields remain host inspection concerns; never infer controller status from owner name.
Provenance → source label and resource identity facts → metadata.labels['audit.kyverno.io/source'], ['audit.kyverno.io/resource.group'], ['audit.kyverno.io/resource.kind'], ['audit.kyverno.io/resource.uid'], ['audit.kyverno.io/resource.hash']. Owner annotation ['audit.kyverno.io/resource.name'] is potentially sensitive; projection omits all annotation values. Hash is identity/provenance, not a health or aggregation-success indicator.
Outcome rows → table + local search + outcome selector → spec.results[i].policy/rule/result/severity. result enum pass/fail/warn/error/skip; severity critical/high/medium/low/info. Search/filter modifies presentation only. Summary → source projection → spec.summary.pass/fail/warn/error/skip, raw recorded counts; no fabricated reconciled totals.
Details → expandable read-only facts → spec.results[i].scored/category/source. Missing scored differs from false. Per-result source does not become a writable global source control. Do not invent absent report-level source field.
Time → UTC string and exact seconds/nanos projection → spec.results[i].timestamp.seconds/nanos. Never round int64 through JS Number. Fixture text preserves 9 fractional digits; not a general date parser.
Resource → UID-aware reference integration → spec.results[i].resources[].apiVersion/kind/name/namespace/uid/resourceVersion/fieldPath. Production must verify discoverable GVK, namespace, permissions and UID before opening host inspector. Name reuse must not navigate silently to a different UID.
Selector → read-only selector description → spec.results[i].resourceSelector.matchLabels and matchExpressions[].key/operator/values; AND semantics; In/NotIn require values, Exists/DoesNotExist do not. Preserve unknown selectors; do not present as an editable query or infer matched resources.
Message/properties → hidden by default → spec.results[i].message/properties. These can contain payloads; no raw reveal offered, logged or captured. Production privacy policy must govern separate explicit access.
