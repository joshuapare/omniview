Issue 309 — Flux source editors. Design proposal, awaiting review; not shipped React.

Workflow: approved #249 isolated interactive HTML composition. No named mock skill available. Web-design-guidelines skill read and current guideline fetched. Controls faithfully compose Input, Select, Button, Tabs/section navigation, Dialog, Alert and repeatable rows; no new generic primitive requested. Existing compact frame: 1000x700, 180px navigation, 32px controls, 13px type, 20x24px content padding. Add-on Flux form provider owns all resource semantics; host supplies identity/discovery/RBAC/source lifetime/admission/revision guard, not Flux hardcoding.

API evidence: source-controller v1.7.0 config/crd/bases, Flux 2.7 archived ExternalArtifact docs. All six kinds namespaced; v1 is served/storage. GitRepository, OCIRepository, Bucket, HelmRepository and HelmChart also serve deprecated v1beta2; this design offers guided v1 only. ExternalArtifact v1 only. Need CRDs, compatible controllers and actual RBAC. No discovery means unavailable; denied is not missing. ObjectLevelWorkloadIdentity must be checked where applicable; schema alone does not prove installation or permission. HelmRepository accessFrom is explicitly not implemented in pinned schema and receives no misleading ACL control.

Coverage: GitRepository create/edit with reference kind, URL/provider, Azure service account, signature mode/key reference, include repository/from/to repeatable rows, sparse directories, ignore and submodules. Git precedence commit > name > semver > tag > branch; combined existing refs stay source-only rather than being collapsed. OCIRepository create/edit with tag/semver/digest, filter, provider, cosign/notation, issuer/subject matcher rows, layer selection and operation, certificate/proxy references and service account. OCI precedence digest > semver > tag. Bucket create/edit with bucket/endpoint/provider/region/prefix, STS provider/endpoint and LDAP references, TLS/proxy/workload identity and exclude patterns. HelmRepository create/edit with HTTP/index versus OCI type, OCI provider, TLS and explicit cross-host credential consequence. HelmChart independently managed create/edit with same-namespace source picker (HelmRepository/GitRepository/Bucket), chart/path/version/strategy, ordered values files, missing-file policy, OCI-source signature options. Controller-owned HelmChart has no Create/save; navigate HelmRelease owner. ExternalArtifact has inspect-only producer connection, revision/digest and empty artifact state; no ordinary create, status editing, reconcile or suspend invention.

Exact paths: field-mapping.json gives each tailored field/control/path. Shared identity: Name -> metadata.name; namespace selector -> metadata.namespace (preview only, bound/locked in edit). Interval text -> spec.interval, timeout -> spec.timeout; three-state suspend -> spec.suspend; Secret picker -> spec.secretRef.name. UI referenceState is fixture capability state, never emitted. Include rows -> spec.include[i].repository.name/fromPath/toPath; directory rows -> spec.sparseCheckout[i]; identity rows -> spec.verify.matchOIDCIdentity[i].issuer/subject; values rows -> spec.valuesFiles[i]. Authentication Secret never loads resolved values. Read-only artifact paths: status.artifact.revision/digest/path/url/size/lastUpdateTime and status.conditions; prototype shows revision/digest/condition boundary only, not fabricated full provenance. External source connection maps spec.sourceRef.apiVersion/kind/name/namespace. Owner link uses metadata.ownerReferences, with controller ownership checked before edit. URL artifact navigation must be mediated in production; mock does not fetch artifact URLs.

Safety/admission design: metadata identity immutable in edit; API snapshot has no extra immutable spec restrictions in these guided v1 schemas. Controller ownership still prevents overwriting generated HelmChart. Reconcile is request-only annotation reconcile.fluxcd.io/requestedAt; suspend reviews spec.suspend=true and stopping future reconciliation. No controller success or signature validity asserted. Source/reference changes may alter downstream deployments. Bucket generic STS=ldap, aws STS=aws, other providers disallow STS; aws STS disallows LDAP secret/cert; Secret and workload service account cannot coexist; service account provider limits apply. Git serviceAccountName requires azure. Certificate Secret on Bucket generic only. HelmRepository insecure/provider only apply to OCI; passCredentials deliberately warns cross-host credential exposure. HelmChart version ignored for Git/Bucket; verify only OCI HelmRepository and does not verify unbundled chart dependencies. Production provider must disable inapplicable controls, preserve existing unsupported combinations in YAML and apply exact schema validation before admission.

Draft boundary: current mock keeps field intent in memory and only explicit mode preference in localStorage. No credentials, source or drafts persist. It demonstrates exact unknown integer/comment fixture retention and byte-for-byte edited invalid source across switches by locking Form after ANY source edit. It does NOT implement arbitrary YAML parsing, AST patching, importing credentials, source-to-form synchronization, server validation, revision concurrency or complete schema validation. Unknown existing versions/shapes must use the same honest source-only fallback. No false lossless-generalization claim. Reset is explicitly destructive-confirmed fixture reset. Generated YAML is prototype serialization only, not submission; no mutations exist.
