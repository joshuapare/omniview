CORE EVENT DEDUP
Within same cluster and namespace, same Event UID across core/v1 and events.k8s.io/v1 is one underlying record. Prefer events.k8s.io/v1 representation, keep alias provenance; never sum aliases. Different/missing UID remains separate. Similar reason/time/message is insufficient. Fixture table illustrates this contract, not a production dedup algorithm. No core Event editor is rebuilt.
