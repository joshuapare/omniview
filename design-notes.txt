HelmRelease v2 — issue 311 design review

Scope: all issue resource components: HelmRelease create/edit, ownership/inspection, reconcile/suspend/resume/reset/force request previews. Generated HelmChart and Helm storage are not additional forms. Add-on Flux editor provider owns semantics; Kubernetes plugin retains discovery, routing, source draft, references and mutation lifecycle.

Sources: helm-controller v1.4.0 resolves to commit 3db605b13009bc80800a79978069e8037cfa6168. Primary CRD: https://github.com/fluxcd/helm-controller/blob/3db605b13009bc80800a79978069e8037cfa6168/config/crd/bases/helm.toolkit.fluxcd.io_helmreleases.yaml . Types: api/v2/helmrelease_types.go, reference_types.go, annotations.go at same commit. helm.toolkit.fluxcd.io/v2 HelmRelease is namespaced. chart and chartRef are mutually exclusive. Template source kinds: HelmRepository, GitRepository, Bucket. Artifact kinds: OCIRepository, HelmChart, ExternalArtifact. ExternalArtifact requires installed controller feature support. Cross-namespace refs depend on controller policy, not just discovery. Mock reference picker deliberately same-namespace only; no claim cross-namespace support proven.

Control -> owned paths
Name, namespace -> metadata.name, metadata.namespace (locked on edit).
Reconcile duration -> spec.interval (required).
Chart mode -> exactly one of spec.chart / spec.chartRef; explicit switch keeps branch drafts in memory but emits only selected branch.
Chart name/path, version -> spec.chart.spec.chart / version. Version applies to HelmRepository; Git/Bucket ignore it. Optional version omission allows upstream latest behavior, never a guessed version.
Template source kind/name -> spec.chart.spec.sourceRef.kind/name. Generated HelmChart remains controller-owned; source namespace defaults by omission.
Artifact kind/name -> spec.chartRef.kind/name. Artifact namespace defaults by omission.
Release/target/storage -> spec.releaseName, targetNamespace, storageNamespace. Optional blanks omit. These are consequential, not falsely schema-immutable; changes may uninstall/reinstall. Kubernetes metadata identity remains immutable.
Values rows -> spec.valuesFrom[i].kind/name/valuesKey/targetPath/optional. Ordered first-to-last merge, same namespace. targetPath affects merge precedence. Missing optional reference differs from missing key or parse errors. No Secret values fetched.
Dependencies -> spec.dependsOn[i].name/namespace/readyExpr. Optional namespace omitted. readyExpr replaces readiness unless AdditiveCELDependencyCheck enabled. Local self-reference blocked; cycles/server CEL not evaluated.
Upgrade strategy -> spec.upgrade.strategy.name. Retry interval -> .retryInterval only for RetryOnFailure. Remediation retries -> spec.upgrade.remediation.retries integer, negative means unlimited. Action -> .strategy rollback/uninstall. Retry strategy excludes remediation serialization.
Upgrade CRD policy -> spec.upgrade.crds Skip/Create/CreateReplace. Replacement cluster-wide consequence visible.
Drift mode -> spec.driftDetection.mode disabled/warn/enabled; enabled can overwrite manual changes.
Operation timeout -> spec.timeout. Impersonation -> spec.serviceAccountName; no authorization claim.
Suspend/resume -> request preview spec.suspend true/false. Suspend does not cancel in-flight reconciliation.
Reconcile -> metadata.annotations[reconcile.fluxcd.io/requestedAt] new token.
Reset/force -> matching requestedAt plus reconcile.fluxcd.io/resetAt / forceAt. No status editing, rollback endpoint or fake successful controller result. Production confirmations and actual verb checks required.

Source-owned advanced fields: spec.values, install, test, rollback, uninstall, kubeConfig, commonMetadata, postRenderers, driftDetection.ignore, chart.spec.verify/valuesFiles/reconcileStrategy, maxHistory, persistentClient and all unknown fields. These are deliberately not rewritten by the proposed adapter. Protected editing required for inline values, annotations, post-render patches and kubeconfig; never a naive raw-secret capture.

Prototype limits: isolated faithful HTML, not React/base-ui shipped UI. Bounded source generator, no arbitrary YAML parser. Every manual source edit is retained verbatim; Form and Review stop rather than claiming bidirectional AST preservation. Exact invalid text/comment/large-integer digits verified only in this fallback path. Production must reuse existing AST draft editor to preserve unknowns, comments, omitted defaults, exact numbers and siblings on supported edits. Existing source fixtures are illustrative, not cluster imports. Source textarea is for non-sensitive synthetic text only, not a protected credential editor. Inline values editing intentionally unavailable in this privacy-safe mock; production uses protected values editing. Mode preference alone persists; drafts never persist. Ownership fixtures lock controls across navigation; actual RBAC/controller/API support not checked. Modal close/reopen lifecycle, async errors, complete name/schema validation, server dry-run, CEL evaluation, charts, templates and controller health not verified. ExternalArtifact warning is a review boundary, not a feature-detection implementation.

Reuse: approved #249 workflow and PR72/74 compact shared frame; intended Dialog, SegmentedControl, FormField, Input, Select/Combobox, Checkbox, Button, Tooltip/Popover and Table/Collapsible compositions. No new generic primitive needed. Resource-specific values merging, source unions, remediation and controller tokens stay in Flux provider. These are explicit prototype limits, not production acceptance.
