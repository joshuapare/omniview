Exact mapping:
All kinds: Name -> metadata.name. Snapshot namespace -> metadata.namespace. Identity locked in edit. Class/content are cluster-scoped.
VolumeSnapshot: Create from selector selects exactly one spec.source.persistentVolumeClaimName or spec.source.volumeSnapshotContentName. Same-namespace PVC picker; existing-content picker is cluster scoped. Class picker -> spec.volumeSnapshotClassName; driver-default choice omits field, never empty string. Source is immutable. Bound class editing locked conservatively in guided edit, not claimed as universal CRD immutability. Status is not editable.
VolumeSnapshotClass: driver selector -> driver (top-level, NOT spec.driver). Policy selector -> deletionPolicy (top-level). Parameter rows -> parameters[key] string values. Guided edit locks driver/parameters conservatively; pinned class CRD does not itself declare these immutable. Deletion policy remains editable; changes do not rewrite existing content policies. Default-class annotation and other metadata remain source-only; no fabricated defaults.
VolumeSnapshotContent: deliberate import requires driver -> spec.driver; existing snapshot handle -> spec.source.snapshotHandle; target snapshot name/namespace -> spec.volumeSnapshotRef.name/.namespace; policy -> spec.deletionPolicy. Optional class -> spec.volumeSnapshotClassName. Optional alpha source volume mode -> spec.sourceVolumeMode, omitted when unknown. Import never writes volumeHandle and never authors companion VolumeSnapshot. Existing spec.source, reference identity and sourceVolumeMode are immutable; guided edit additionally locks driver/class conservatively. Deletion policy remains editable.
Generated content: inspect-only, no ordinary create or source edit. Dynamic spec.source.volumeHandle and controller-populated status.snapshotHandle remain controller owned. Reference UID, API version and kind belong to full binding verification. Graph explicitly reports UID unverified rather than successful binding. status.readyToUse absence means unknown, not false; restore size and creation time remain unknown in fixtures. Error display would require sanitization; no raw driver errors appear here.

Consequences: Delete may remove content and physical snapshot. Retain leaves cleanup responsibility and potential charges. Snapshot creation requests storage work; no consistency/application-quiescence guarantee. Delete review contains no delete button or mutation; implementation needs fresh permissions, reciprocal binding/UID checks and explicit confirmation. Never delete/recreate as edit shortcut.
