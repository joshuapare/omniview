Scope: imagepolicy.k8s.io/v1alpha1, k8s.io/api v0.35.0, Kubernetes v1.35.0. ImageReview is non-namespaced with no generated CRUD verbs. spec.namespace identifies the admitting Pod namespace. No collection, Create, Edit, Save status, or replay.

Field mapping / ownership:
apiVersion,kind -> identity subtitle and source -> fixed registered GVK.
metadata -> optional evidence metadata; free-text omitted from this safe projection, never authored.
spec.namespace -> read-only Pod namespace tile -> API server owns.
spec.containers[i].image -> image rows -> API server owns atomic list. No container names or per-image decision invented.
spec.annotations[key] -> count-only policy annotation summary -> API server filters *.image-policy.k8s.io/*; all values excluded.
status.allowed -> true/false decision tile -> webhook owns; absent/invalid response is unknown.
status.reason -> synthetic denial reason in decision; redacted in source -> webhook owns. Production must sanitize free text.
status.auditAnnotations[key] -> count-only summary -> backend owns suffix keys; API server prefixes imagepolicywebhook.image-policy.k8s.io/. Values excluded.
