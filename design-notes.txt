FIELD -> CONTROL -> OWNED PATH
Name -> text, locked during edit -> metadata.name. Namespace fixed preview -> metadata.namespace. API version/kind fixed. No immutable spec-field rule found in v1 schema; identity follows Kubernetes immutable identity rules. Status and inventory never editable.
Source kind -> explicit GitRepository/OCIRepository/Bucket/ExternalArtifact select -> spec.sourceRef.kind. Source name -> existing fixture choice / unresolved reference -> spec.sourceRef.name. Source directory -> text -> spec.path, omitted means source root. Source namespace/API version retained via source-only editing -> spec.sourceRef.namespace/apiVersion. Cross-namespace permission/controller policy must be discovered; no cross-namespace support claimed by fixture.
Interval -> raw duration text -> spec.interval, required. Prune -> explicit true/false choice -> spec.prune, required; no guessed default.
Target namespace -> optional text -> spec.targetNamespace. Does not create namespaces.
Deletion policy -> omission or MirrorPrune/Delete/WaitForTermination/Orphan -> spec.deletionPolicy. MirrorPrune follows prune; Orphan leaves resources. Delete removes managed resources; WaitForTermination waits up to timeout. Choice requires review.
Wait / force / suspend -> optional boolean selects -> spec.wait / force / suspend. Wait ignores healthChecks. Force may recreate on immutable resource-field failure. Suspend does not stop started executions.
Timeout / retry interval -> duration text -> spec.timeout/retryInterval. Omitted defaults remain omitted.
Dependencies -> add/remove name + namespace rows -> spec.dependsOn[i].name/namespace.
Health -> add/remove resource name + kind rows -> spec.healthChecks[i].name/kind. API version/namespace source-only -> spec.healthChecks[i].apiVersion/namespace.
Non-sensitive substitutions -> add/remove string pairs -> spec.postBuild.substitute[key]; values remain strings. Sensitive values must use references; never import resolved values.
Substitution references -> add/remove kind + name -> spec.postBuild.substituteFrom[i].kind/name. optional source-only. Production must use enum picker and validate duplicates; fixture row text is not schema validation.
Decryption -> none/sops -> spec.decryption.provider; existing Secret name -> spec.decryption.secretRef.name; cloud SA name -> spec.decryption.serviceAccountName. Static credentials take precedence. No Secret values fetched or shown; do not infer key validity.
Apply identity -> text -> spec.serviceAccountName. Separate from decryption SA and remote kubeConfig authentication.
Advanced SOURCE-ONLY -> spec.images[*].name/newName/newTag/digest (digest wins), patches[*].patch/target, components[], ignoreMissingComponents, namePrefix/nameSuffix, commonMetadata.labels/annotations, kubeConfig.configMapRef.name OR kubeConfig.secretRef.name/key (exactly one), dependsOn[*].readyExpr, healthCheckExprs[*].apiVersion/kind/current/failed/inProgress. No fake generated helper resource or credential form. Advanced YAML is editable, not a no-op preview.

BOUNDARIES / PREREQUISITES
Installed v1 discovery plus create/update verbs and actual authorization required. CRD schema does not prove controller availability. Source lookup loading/empty/denied/unavailable are explicit fixture choices. ExternalArtifact requires installed controller capability; decryption workload identity and remote kubeConfig support require actual deployment configuration. ReadyExpr replaces built-in dependency readiness unless AdditiveCELDependencyCheck enabled; do not claim this gate enabled. Controller flags may restrict cross-namespace refs or set default service account.
Git-owned scenario locks direct editing and routes intent to source-of-truth work; no fake repository write. Direct-owned edit locks name and namespace. Production must inspect ownerReferences, managedFields, Git labels and revision conflicts rather than infer ownership solely from a dropdown.
Reconcile request connects to metadata.annotations['reconcile.fluxcd.io/requestedAt']; suspend/resume to spec.suspend true/false. Only request review is shown, never action success. Inventory connects to status.inventory.entries[id,v]. Drift remains explicitly unavailable without live comparison; no rebuilt dashboard.

SOURCE SAFETY
One in-memory draft feeds form and YAML. Initial projection is JSON flow syntax, valid in YAML, with a comment. This is intentionally not a YAML AST implementation. Any manual source edit freezes Form; exact raw text, unknown content, comments, omission, scalar spelling and invalid text remain untouched thereafter. No claim of editable form round-trips after arbitrary YAML. Review disabled for manual source, because no parser/server validation exists here. No clipboard or credential import. No draft storage. Only explicit presentation preference uses mock-310-view localStorage.
